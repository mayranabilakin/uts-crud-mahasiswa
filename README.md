# Aplikasi CRUD Data Mahasiswa

Aplikasi web sederhana untuk mengelola data mahasiswa menggunakan Python, Flask, SQLite, HTML, dan CSS.

## Fitur
- Menampilkan daftar mahasiswa.
- Menambahkan data mahasiswa.
- Mengedit data mahasiswa.
- Menghapus data mahasiswa.
- Memvalidasi kolom wajib, NIM, angkatan, dan IPK.
- Mencegah penggunaan NIM yang sama.
- Menghitung lama studi berdasarkan tahun angkatan.

## Teknologi
- Python
- Flask
- SQLite
- HTML
- CSS
- Git dan GitHub

## Cara Menjalankan
1. Pastikan Python sudah terinstal.
2. Aktifkan virtual environment.
3. Instal Flask jika belum tersedia:

   `pip install flask`

4. Jalankan aplikasi:

   `python app.py`

5. Buka alamat lokal yang ditampilkan di terminal, biasanya `http://127.0.0.1:5000`.

## Catatan
Database SQLite digunakan untuk menyimpan data mahasiswa secara persisten. File database lokal tidak disertakan dalam repository.
